# Resource-pack status

**Status: PARTIAL; NOT LIVE-TESTED.** The source pack is in `src/main/resources/resource-pack`; 20 firearm item definitions and seven model JSONs share seven texture paths. Five invalid texture placeholders were replaced with 64×64 pixel-art PNGs (`pistol`, `revolver`, `rifle`, `shotgun`, `smg`). The `sniper.png` and `heavy.png` files remain invalid because asset generation could not complete. The definitions use the `zapocalypsecore:firearms/<item-id>` keys assigned by the custom-item factory.

Firearms retain configured vanilla base materials and XSeries-matched vanilla sounds. Item identifiers, model references, ammunition IDs and reload configuration were statically audited with no mismatch found. The pack targets pack format 46; it has not been loaded in a live Minecraft 26.3 client, and the two invalid texture files prevent claiming that every firearm renders correctly. The plugin's functional power/CCTV/security devices are registered against existing blocks and do not currently have custom item/block resource-pack mappings.

Maven packaging creates `ZApocalypseCore-<version>-resource-pack.zip` alongside the plugin JAR. Upload the ZIP through your server host's resource-pack delivery setup and provide its public URL to clients; this project does not host files or generate a download URL/hash. Vanilla icons remain as fallbacks when a client declines or cannot load the pack.
